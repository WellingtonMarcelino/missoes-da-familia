# 🏡 Missões da Nossa Família

Aplicativo (PWA) de tarefas, estudos, pontuação e recompensas da família.

- **App publicado:** https://wellingtonmarcelino.github.io/missoes-da-familia/
- **Banco de dados:** Supabase (região São Paulo). Estrutura completa em `banco.sql`.
- **Código-fonte:** pasta `codigo/` (React + Vite). Testes das regras em `codigo/test/`.

As permissões são aplicadas no próprio banco (Row Level Security): crianças só marcam as próprias tarefas,
não alteram pontos e não aprovam tarefas.
